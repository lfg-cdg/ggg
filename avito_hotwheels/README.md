# Avito → Telegram: новые объявления «hot wheels»

Раз в минуту открывает поиск Авито по всей России, отсортированный по дате
(`https://www.avito.ru/all?q=hot+wheels&s=104`), и присылает в Telegram каждое новое объявление:
фото, название, цену, город и ссылку.

## Запуск

1. **Создайте бота.** В Telegram напишите [@BotFather](https://t.me/BotFather) → `/newbot` → скопируйте токен.
2. **Установите зависимости** в виртуальное окружение (нужен Python 3.10+):
   ```bash
   python -m venv .venv
   .venv/bin/pip install -r avito_hotwheels/requirements.txt
   ```
   Дальше все команды запускайте через `.venv/bin/python` вместо `python`
   (на Windows: `.venv\Scripts\python`).
3. **Настройте `.env`.** Скопируйте `avito_hotwheels/.env.example` в `.env` в корне репозитория и впишите `TG_TOKEN`.
4. **Узнайте свой chat_id.** Напишите своему боту любое сообщение и выполните:
   ```bash
   python -m avito_hotwheels chatid
   ```
   Полученную строку `TG_CHAT_ID=...` вставьте в `.env`.
5. **Запустите:**
   ```bash
   python -m avito_hotwheels
   ```
   При первом запуске бот запоминает текущие объявления и пишет «Бот запущен».
   Дальше приходят только новые. Остановить: `Ctrl+C`.

Бот работает, только пока запущен скрипт. Чтобы он работал круглосуточно, запустите его на VPS
или домашнем сервере (например, в `tmux`, `screen` или как службу systemd).

## Настройки (`.env`)

| Переменная    | По умолчанию    | Что значит                                  |
|---------------|-----------------|---------------------------------------------|
| `TG_TOKEN`    | —               | токен бота от BotFather                     |
| `TG_CHAT_ID`  | —               | куда слать (ваш чат, группа или канал)      |
| `AVITO_QUERY` | `hot wheels`    | поисковый запрос                            |
| `INTERVAL`    | `60`            | секунд между проверками (±15% случайно)     |
| `TG_PROXY`    | пусто           | прокси только для Telegram (если он заблокирован) |
| `PROXY`       | пусто           | прокси только для Авито `http://user:pass@host:port` |
| `DB_PATH`     | `avito_seen.db` | где хранить ID уже отправленных объявлений  |

## Если Telegram не подключается

Ошибка `Connection reset by peer` или сообщение «Не могу подключиться к api.telegram.org» значит,
что провайдер блокирует Telegram. Есть два варианта:
- включить VPN на всём компьютере (но Авито с зарубежного IP может блокировать чаще);
- лучше: впишите в `.env` локальный прокси вашего VPN-клиента, например
  `TG_PROXY=socks5h://127.0.0.1:1080`. Тогда через VPN пойдёт только Telegram, а Авито будет открываться напрямую.

`chat_id` можно узнать и без скрипта: напишите в Telegram боту @userinfobot, он ответит вашим ID.

## Если Авито блокирует

При ответе 403/429 или странице «Доступ ограничен» бот один раз пишет об этом в Telegram
и делает паузы: 5, 10, 20, потом по 30 минут. Когда доступ вернётся, бот сообщит и продолжит.

Что делать, если блокировки частые:
- увеличьте `INTERVAL` до 120–300 секунд;
- не запускайте бота с IP дата-центра: с домашнего интернета блокируют реже;
- укажите резидентный прокси в `PROXY`.

Если на странице найдено 0 объявлений без явной блокировки, значит, скорее всего, Авито поменял
вёрстку. Бот сохранит страницу в `avito_last.html`, а селекторы нужно поправить в функции
`parse()` в `bot.py`.
