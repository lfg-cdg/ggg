# NBA totals analyzer

CLI-агент для анализа тоталов (ТБ/ТМ) матчей NBA на бесплатном ESPN API (без ключа).

```bash
pip install -r requirements.txt
python -m nba_totals predict                      # матчи сегодня (дата по US Eastern)
python -m nba_totals predict --date 2026-03-01    # любая дата
python -m nba_totals predict --line CHI=231.5 --line MEM@CHI=231.5   # линия вручную
python -m nba_totals backtest --season 2026       # бэктест сезона 2025-26
python -m nba_totals predict --injury-factor 0.45 --b2b 2 --threshold 7 --last-n 15
python -m pytest -q
```

Все настройки по умолчанию — в `nba_totals/config.py`. Ответы API кэшируются в `cache/`
(из бокс-скоров сохраняются только нужные поля: весь сезон занимает ~8 МБ).

## Модель

1. Форма команды за последние N игр регулярки (по умолчанию 10), смешанная 50/50 с формой
   только дома (для хозяев) или только в гостях (для гостей).
2. Владения = FGA − OREB + TOV + 0.44·FTA → темп, ORtg и DRtg (очки на 100 владений).
3. Ожидаемые очки = темп_A·темп_B / темп_лиги × ORtg_A·DRtg_B / рейтинг_лиги / 100.
4. Поправка на состав относительно окна формы: игрок не играет → −очки·доля_сыгранных_игр;
   игрок вернулся → +очки·доля_пропущенных. Всё умножается на `injury_loss_factor`
   (часть очков забивают замены). Статусы: Out 100%, Doubtful 75%, Questionable 40%, Day-To-Day 30%.
5. Back-to-back: −1.5 очка команде, которая играла вчера.
6. Ставка, если |прогноз − линия| ≥ 5.

## Особенности данных ESPN

- В `/injuries` нет `athlete.id` — он берётся из ссылки `.../player/_/id/<id>/...`.
- ESPN в основном использует статус `Day-To-Day`, а не `Questionable`.
- Блок `injuries` в `summary` старого матча — это **текущий** отчёт, а не отчёт на день игры.
  Поэтому для прошлых дат «не играл» = игрок из окна формы, которого нет в бокс-скоре.
- Линия на табло есть только до матча; после матча она берётся из `summary.pickcenter`.
- В межсезонье окно формы — прошлый сезон, поправка на состав отключается.

## Бэктест 2025-26 (1152 матча, у 979 есть линия DraftKings)

| | MAE | смещение |
|---|---|---|
| модель | 16.22 | −1.99 |
| модель без поправки на состав | 16.05 | −0.64 |
| линия букмекера | 14.66 | −0.16 |

Ставки при пороге 5: 578 ставок, 52.4% угаданных — это ровно точка безубыточности при коэффициенте −110.
Модель не обыгрывает линию. В бэктесте составы известны по факту (бокс-скор), то есть это
оптимистичная оценка.
